

auth_worker.php
(The Logic): This file does the invisible heavy lifting:
Connects to the database.
Checks if the username is already taken.
Hashes the password.
Inserts the row into the Users table.
The Result: If successful, the worker sends a "Success" signal back to index.php, which then unlocks the Character Creation side of the screen.


engine.js
(The Orchestrator): Coordinates all Manager modules. Synchronizes the initial game state, handles general UI updates, and dispatches global system events.

navigation.js
(The Interface): Manages the movement Experience. Handles compass UI logic and dispatches traversal requests to move_player.php.

inventory.js
(The Interface): Manages item interactions and inventory rendering. Adjudicates the "Experience" of taking items and provides visual feedback for carrying capacity.

dialogue.js
(The Social Interface): Manages branching social interactions. Handles the "Practice Loop" (TTS/STT), re-skins the console for dialogue mode, and manages conversation state.

map.js
(The Visualizer): Renders the 7x7 relative Mini-Map grid. Handles coordinate logic and Z-level filtering for vertical navigation.

get_dialogue.php
(The Judge): Fetches the specific active dialogue node for an NPC based on the character's current state.

get_inventory.php
(The Judge): Fetches the current inventory "Truth" for the active character to sync the sidebar.

get_player.php
(The Judge): Fetches current character stats and location for general UI synchronization.

get_room.php
(The Judge): Fetches the environmental "Truth" for a location, including bilingual descriptions, NPCs, items, map coordinates, and party members.

move_player.php
(The Judge): Adjudicates movement requests. Validates exits and updates character and follower location states in the database.

process_command.php
(The Stateless Judge): Interprets spoken or typed input. Categorizes intent (navigation, interaction, social, combat) and applies linguistic gold rewards.

process_item.php
(The Judge): Adjudicates item interactions. Enforces Strength-based carrying capacity and updates ownership truth in the ItemInstances table.

reset_game.php
(The Judge): Handles player death protocols. Resets world position to the last checkpoint and applies the 10% gold penalty.

speech.js
(The Ears): Interfaces with the Web Speech API to capture audio input. Performs Levenshtein similarity math to grade pronunciation tiers.

ui.js
(The Mouth): Manages Text-to-Speech (TTS) output. Handles karaoke-style word highlighting and system audio effects like success/error chimes.

combat.js
(The Interface): This is your current file. It stays .js. It handles the "Speech-to-Text" and the visual "Combat Overlay."

handle_victory.php
(The Judge): Processes monster death, dropping loot instances into the room and distributing attribute boosts to the player.

mark_dead.php
(The Judge): Updates NPC state to 'isDead' upon HP reaching zero.

flee.php
(The Judge): Adjudicates escape attempts during combat, calculating probability of success.

db_config.php
(The Bridge): Establishes the authoritative PDO connection to the MySQL database.

navbar.php
(The Navigator): Provides global navigation links restricted by authentication and admin status.

process_combat.php
(The Judge): Handles the actual "Truth" of combat. Adjudicates turn logic, calculates damage based on grading and attributes, and updates HP/Gold states.

content_auditor.php
(The Auditor): An administrative QA tool that crawls world nodes to detect "Linguistic Holes" or broken navigation links.

init.php
(The Heartbeat): Standardizes error reporting, session management, and global constants across all backend workers.

voice_calibration.php
(Onboarding Manager): Provides a safe practice environment for players to test microphone setup and pronunciation without game consequences.

spawner_worker.php
(The World Birth Judge): Handles the complex logic of copying static library blueprints (NPCs, Items, Rooms) into a character's unique state tables during creation.

auto_mapper.php
(Administrative Utility): Crawls world nodes to automatically calculate and store 3D coordinates (X, Y, Z) for the mini-map.

process_dialogue.php
(The Judge): Adjudicates dialogue outcomes. Calculates similarity for chosen responses, updates NPC interaction state, and triggers recruitment or item rewards.

editor.php
(Content Judge): Provides a comprehensive CRUD interface for administrators to modify the live database library of locations, items, NPCs, and users.
